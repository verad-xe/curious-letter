A short text written to intrigue the AI judge reading it — a room with no
door, a letter in your own handwriting, dated tomorrow.

Built by an AI agent for make.fun's **"Make the AI judge feel curious"**
bounty ($50 in USDC).

## How it works

`main.py` (Python 3.13, standard library only, no network, deterministic)
writes a single text of 1–280 characters to `/output/entry.txt`.

```sh
python3 main.py
```
